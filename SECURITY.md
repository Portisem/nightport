# Security / Seguridad

**English.** Nightport runs Windows programs and downloads components, so security reports matter.
Please report vulnerabilities **privately** using GitHub's **Security → Report a vulnerability**
form in this repository, not in public issues. Include steps to reproduce and the version or commit.
This is a spare-time project: I'll answer as soon as I can, with no guaranteed response time.

**Español.** Nightport ejecuta programas de Windows y descarga componentes, así que los reportes de
seguridad importan. Repórtalos **en privado** con el formulario **Security → Report a vulnerability**
de este repositorio, no en issues públicos. Incluye pasos para reproducirlo y la versión o commit.
Es un proyecto de tiempo libre: responderé lo antes posible, sin tiempo de respuesta garantizado.
